## 🔢 Numerical Computing with NumPy

This repository includes several projects that utilize **[NumPy](https://numpy.org/)** — the foundational Python library for numerical computing.

### ⚡ Why NumPy?
NumPy provides:
- High-performance **multi-dimensional arrays** (`ndarray`)
- Fast and efficient **element-wise operations**
- Support for **linear algebra**, **Fourier transforms**, and **random number generation**
- Powerful tools to work seamlessly with other libraries like **Pandas**, **Matplotlib**, and **Scikit-learn**

### 🧮 Core NumPy Features Used:
| Function/Method           | Description                                                 |
|---------------------------|-------------------------------------------------------------|
| `np.array()`              | Create arrays from lists or tuples                          |
| `np.arange()`, `np.linspace()` | Generate sequences of numbers                      |
| `np.mean()`, `np.median()`| Perform statistical calculations                            |
| `np.sum()`, `np.max()`, `np.min()` | Aggregate data across axes                      |
| `np.reshape()`, `np.transpose()` | Reshape and reorient arrays                     |
| `np.where()`              | Conditional selection                                       |
| `np.random.rand()` / `randint()` | Generate random numbers                        |
| `np.dot()`, `np.linalg.inv()` | Linear algebra operations                          |

### 📁 Projects That Use NumPy:
- **IMDB Movie Analysis** – Efficient numeric operations for ratings and durations.
- **ML Preprocessing** – Feature scaling, matrix computations, and random number generation.

> NumPy powers the numerical backbone of the data workflows in this repository, ensuring fast and efficient computations throughout.
